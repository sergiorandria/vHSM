# vHSM REST API

Go (Gin) backend for vHSM — thesis lifecycle, HSM signing (PKCS#11), MinIO notarization, and Fabric lifecycle.

## Prerequisites

* Go 1.21+
* Running Fabric network (`network/fabric_configuration/docker` or `/etc/vhsmd`) — see `network/fabric_configuration/real-network/README.md`
* MinIO (or S3-compatible) + HSM `.so` (`HSM_MODULE_PATH`)
* Fabric crypto material (`/etc/vhsmd` or `network/fabric_configuration/docker` fallback via `utils.LoadConfig`)

## Configuration (.env)

Secrets are loaded from `rest_api/.env` (gitignored) via `loadDotEnv` in `cmd/api/main.go:31`. Existing env vars take precedence.

```
JWT_SECRET=change-me
JWT_TTL_MINUTES=60
MINIO_ENDPOINT=localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET=thesis
HSM_MODULE_PATH=/usr/lib/libvhsm.so
HSM_TOKEN_LABEL=MyToken
HSM_PIN=1234
HSM_LABEL=thesis-key
HSM_SIGN_LABEL=sign-key
LDAP_URL=ldap://localhost:389
LDAP_BIND_DN=cn=admin,dc=example,dc=com
LDAP_BIND_PASSWORD=admin
LDAP_USER_BASE_DN=ou=users,dc=example,dc=com
LDAP_USER_FILTER=(uid=%s)
LDAP_GROUP_BASE_DN=ou=groups,dc=example,dc=com
LDAP_ROLE_ATTR=cn
LDAP_USE_TLS=false
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://localhost:8080
PORT=8080
SIGNATURE_CHANNEL_NAME=signaturechannel
SIGNATURE_CHAINCODE_NAME=signature_ledger
```

Fabric connection uses `/etc/vhsmd/default-fabric.conf` + `vhsmd.env` (generated by `Conf_with_fabric-CA` scripts). See `docs/LEDGER_E2E_RUNBOOK.md`.

## Run

```bash
cd rest_api
go mod download
# create .env (see above)
go run ./cmd/api        # :8080
# or
go build -o vhsm-api ./cmd/api && ./vhsm-api
```

The API serves the built web UI at `/` from `web/dist` (SPA fallback). If `web/dist` is missing, `/api/*` still works; UI paths return 404.

## Authentication & RBAC

* `POST /api/v1/login` → LDAP `Authenticate` → `IssueToken` (HS256, `tokenTTL` = `JWT_TTL_MINUTES`). Returns `{token, username, roles, expires_in}`.
* `Authorization: Bearer <jwt>` required for all `/api/v1/*` (via `authRequired` `main.go:364`).
* `requirePermission(action)` checks `internal.HasPermission(roles, action)` against `roles.go` `actionPermissions` (fail-closed). Key actions: `ReadThesis`, `CreateThesis`, `SubmitJuryGrade`, `SignPv`, `NotarizeDocument`.

## Endpoints

### Thesis lifecycle (Fabric `template_chaincode`)

| Method | Path | Permission | Description |
|--------|------|------------|-------------|
| `POST` | `/api/v1/login` | — | LDAP login → JWT |
| `GET` | `/api/v1/theses/:thesisId` | `ReadThesis` | `GetThesis` — current record |
| `GET` | `/api/v1/theses` | `ReadThesis` | `GetAllTheses` |
| `GET` | `/api/v1/theses/:thesisId/jury-status` | `ReadThesis` | `GetJuryStatus` — graded/signed counts |
| `GET` | `/api/v1/theses/:thesisId/history` | `ReadThesis` | `GetThesisHistory` — per-tx history |
| `POST` | `/api/v1/theses` | `CreateThesis` | `CreateThesis` (superadmin) |
| `POST` | `/api/v1/theses/:thesisId/grades` | `SubmitJuryGrade` | Per-jury `SubmitJuryGrade` (juror = JWT username) |
| `POST` | `/api/v1/theses/:thesisId/pv-signature` | `SignPv` | First signer uploads `Pv` multipart; others sign stored `HashPv` (hash-immutability enforced) |
| `POST` | `/api/v1/theses/:thesisId/document` | `NotarizeDocument` | Encrypt+MinIO+Sign thesis PDF → `NotarizeDocument` |

### Proof / audit (read-only)

| Method | Path | Permission | Description |
|--------|------|------------|-------------|
| `GET` | `/api/v1/proof/:recordId` | `ReadThesis` | `signature_ledger.GetRecord` via `sigClient.EvaluateTransaction` — block inclusion proof |
| `GET` | `/api/v1/audit/tail` | `ReadThesis` | Placeholder 501 — tail hash owned by C++ `vhsmd` daemon |

### Fabric lifecycle — Docker-based blockchain environment (`internal.FabricManager`)

All use `authRequired`; read = `ReadThesis`, mutations = `CreateThesis` except `POST /sign` (`SignPv`).

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/fabric/status` | Full topology: orderer, orgs/peers, channels, chaincodes, block height |
| `GET` | `/api/v1/fabric/containers` | Container list |
| `POST` | `/api/v1/fabric/network` | `CreateNetwork(payload)` — writes `network.env` (builder wizard) |
| `POST` | `/api/v1/fabric/deploy` | `DeployNetwork()` — async job: generate → enroll → `docker compose` → peer join → chaincode approve/commit |
| `GET` | `/api/v1/fabric/jobs` | List jobs |
| `GET` | `/api/v1/fabric/jobs/:id` | Job status/progress/steps |
| `GET` | `/api/v1/fabric/transactions?limit=50&channel=` | Recent ledger transactions (max metadata) |
| `GET` | `/api/v1/fabric/transactions/stream` | SSE live stream (poll 3s) |
| `GET` | `/api/v1/fabric/audit` | Audit anchor history |
| `POST` | `/api/v1/fabric/audit/verify` | `VerifyAudit()` — HMAC chain + ledger cross-check (409 on tamper) |
| `POST` | `/api/v1/fabric/audit/simulate-tamper` | Toggle tamper simulation |
| `PUT` | `/api/v1/fabric/peers/:peerId` | `UpdatePeer` — rename/host/channel re-assign (no deletion) |
| `POST` | `/api/v1/fabric/sign` | `SignWithHSM(payload)` — SHA-256 + PKCS#11 `C_Sign` → ledger anchor |

## Security notes

* LDAP `UseTLS=false` logs a startup warning (`main.go:211`) — enable `LDAP_USE_TLS=true` for non-local.
* CORS allowlist via `CORS_ALLOWED_ORIGINS` (exact match, `Allow-Credentials` only for allowed origins).
* PV hash immutability: first signer's upload sets `HashPv`; later uploads are cross-checked (`main.go:623`).
* HSM keys never leave the module; document blobs are AES-GCM encrypted before MinIO.
